2. 沟通话术（筛选通过后按序触发）

S1 公司介绍 + 询问意愿（合并为一条，通过筛选后发送）

你好，我们公司是一家手游研发公司，08年成立，目前人员规模已达到700+，上线运营及在研项目10余个，包含slg、卡牌rpg、小游戏多种类型，风格多样，比如欧美卡通、国风写实、二次元等等。福利完善，团队氛围好。我们有一个游戏经历调查问卷，你有空做吗？
  • 候选人回复同意 / 有空 / 好的 → 进入 S3
  • 候选人拒绝 / 没空 → 标记「婉拒笔试」，礼貌收尾，不再跟进
  • 72h 未回复 → 标记流失，不催办

S3 发送问卷链接 + 邮箱（候选人同意后）

这是笔试链接：【TEST_LINK】

做完后请将该问卷和你的简历一起发到我的邮箱，邮箱地址：hr-rpg@youkia.net

S4 筛选不通过 → 婉拒（不进入 S1）

感谢您的关注～这个岗位目前对专业方向（数学/计算机相关）有硬性要求，和您的背景不太匹配，暂时无法继续推进。后续有合适的岗位会再联系您，祝求职顺利！

S5 转人工（内部提示，不发给候选人）

【转人工】候选人 {NAME}｜岗位：游戏执行策划｜原因：{敏感问题/置信度低/多次追问}｜最近消息：{MSG}

S6 例外兜底：在线资料读不到学历/专业时 → 追问（限 1 次）

您好！方便简单介绍一下您的学历、所学专业，以及平时玩得比较深的游戏吗？简单一两句话就可以～
  • 补充后回到筛选判定；拒绝补充或 48h 未回 → 标记流失。

S7 收到候选人主动发送的附件简历 → 不接收（任意阶段触发）

系统对「对方想发送附件简历给您」卡片自动点「拒绝」，并发送：

简历先不用发到聊天里哦～请您完成游戏经历调查问卷后，将问卷和您的简历一起发送到邮箱 hr-rpg@youkia.net 即可。
  • 约束：若该候选人已处于「婉拒」终态，则仅拒绝附件、不再回复。

3. AI 判定逻辑

收到候选人主动沟通 →
  0. 敏感/异常消息（问薪资细节、投诉、情绪化）→ S5 转人工
  0.5 候选人发附件简历 → 自动拒绝 + S7 告知邮箱提交方式（已婉拒者仅拒绝不回复）
  1. 读候选人 BOSS 在线资料的教育经历（学历/专业）
     ├─ 读得到 → 筛选判定
     └─ 读不到 → S6 追问一次 → 回到步骤 1
  2. 筛选判定：
     A. H1学历 + H2专业 均满足 → 发送 S1（公司介绍+询问意愿）→ 同意后 S3 发链接
     B. 任一硬性条件明确不满足 → S4 婉拒
     C. 专业边界模糊/置信度低   → S5 转人工

筛选信息来源优先级

1. BOSS 在线资料的教育经历（学校/学历/专业）  ← 主要来源，招聘端可见
2. 附件简历 / 粘贴的简历文本（候选人主动发时）
3. 打招呼语
4. AI 追问（限 1 次）

4. 硬性筛选条件（一票否决）

#条件判定标准
H1学历大学本科及以上（含应届/大四在读）
H2专业数学类或计算机类相关专业（含泛工科，见白名单）
H3经验无要求
H4关键词沟通或资料中出现「游戏策划」相关意向/经历

专业白名单（含泛工科，已确认计入）

  • 计算机类：计算机科学与技术、软件工程、网络工程、信息安全、物联网工程、数据科学与大数据技术、人工智能
  • 数学类：数学与应用数学、信息与计算科学、统计学、应用统计学、金融数学
  • 泛工科：电子信息工程、通信工程、信息工程、电子信息科学与技术、电子科学与技术、微电子科学与工程、光电信息科学与工程、自动化

判定原则：白名单内直接通过；白名单外但明显偏理工/编程方向的 → 置信度低，转人工；纯文科（语言、艺术、管理、法学等）→ 不通过。

5. 软性加分（仅记录，不影响通过）

  • 精通某品类/某款游戏，能讲出具体理解
  • 有美术背景或作品集
  • 有竞品分析、配置表维护、数据整理经历
  • 玩过公司产品

6. 状态流转

新消息 → 筛选中（读在线资料）
        ├─ 通过 → S1 已发（介绍+询问意愿）
        │            ├─ 同意 → S3 已发问卷 → 等待邮箱回复（无时限，不催办）
        │            ├─ 拒绝 → 终态「婉拒笔试」
        │            └─ 72h 未回 → 终态「流失」
        ├─ 不通过 → S4 婉拒 → 终态
        └─ 转人工 → 等人工
任意阶段收到附件简历 → 自动拒绝 + S7 提示邮箱提交（已婉拒者不回复）
收到邮件（问卷+简历发到 hr-rpg@youkia.net）→ 标记「待批改」，通知人工
未发回邮箱 → 不处理，自然流失
