怎么接入
  1. 确认外部 AI 支持本机命令或 HTTP 请求。
  2. 同机运行使用默认地址和路径；异机运行填写已部署的 HTTPS API 地址，并在 AI 所在机器安全配置凭据文件。
  3. 点击“复制接入提示词”，粘贴给 CC Connect 等工具。
  4. 先取得一次真实查询报告，再配置工具支持的定时巡检。
127.0.0.1 指 AI 自己所在的机器。异机不能直接使用这个地址。页面不展示 Token，也不需要把密钥贴进提示词。
建议每60秒巡检。复制提示词不会自动创建定时任务；只有工具确认实际执行成功后，才算已接入。
