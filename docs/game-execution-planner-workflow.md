## 2. 优化后的主流程

1. **接收主动沟通**：候选人主动沟通本职位后，核对公司账号、候选人和职位；按用户最新要求，共用于游戏执行策划、数值策划、资深数值策划；保留原始职位名称与账号上下文，不用于客户端岗位，未列出的职位先人工确认。
2. **处理停止条件**：页面异常或身份不一致则暂停；已人工接管的候选人不再自动操作。薪资细节、投诉、争议、无法理解或没有答案的问题生成S5内部待办，不把通知发给候选人。“情绪化”应以具体投诉/争议内容作为证据，不以语气自动评价人。
3. **读取已有信息**：在线教育经历为主，辅以已可见的粘贴简历文字、招呼内容和后续回复；提取原文、来源位置、学历阶段、专业和策划意向。冲突不能用“高优先级来源”直接覆盖。
4. **初筛**：H1/H2/H4均明确满足才通过；明确不满足则形成S4婉拒草稿；任何缺失、歧义或矛盾不得当作不符合。专业白名单只证明H2通过，不代表全部初筛通过。
5. **仅一次补问**：只问缺少的硬条件；已知内容不重复问。仅缺意向用S6_INTENT，其余用S6并列出实际缺项。游戏经历可选。此预算是每个候选人本岗位流程一次，不是每个字段一次。
6. **询问问卷意愿**：通过初筛后才准备S1。S1包含公司介绍和问卷意愿问题；明确同意且回应的是这次问卷邀请才进入S3；“好的”如果是在回答其他问题，不算问卷同意。硬条件筛选阶段不发任何筛选消息。
7. **发问卷**：验证固定链接、岗位、候选人、同意证据及同一发送意图未处理。链接缺失时保留待发状态，不发送占位符、不因同意就标记已发。
8. **等待提交**：发题后不设完成期限、不催办，不自动变成流失。聊天中“已发邮件”只是自述。
9. **收件确认与人工批改**：确认邮件身份及岗位关联，同时收到问卷和简历才标记待批改。只收到一项记“材料不全”；无法关联记人工核对，不靠同名强行绑定。

上述是目标流程设计。当前实际执行仍为只读/草稿，未实现教育详情读取、自动发送、附件拒收、计时任务或邮箱同步；固定链接未确认前不能发 S3。本次不发消息、不点附件卡片。

## 3. 状态与计时

| 状态 | 事件 | 下一状态/动作 |
|---|---|---|
| 筛选中 | 缺硬条件且未问过 | 生成S6/S6_INTENT；收到发送成功回执后进入等待补充 |
| 等待补充 | 信息齐备 | 回到筛选 |
| 等待补充 | 明确拒绝补充或48小时未回 | 流失，不追问 |
| 等待补充 | 有回复但仍缺项 | 转人工，不再补问、不假定不合格 |
| 筛选中 | H1/H2/H4明确满足 | 生成S1；发送成功后进入等待问卷意愿 |
| 筛选中 | 硬条件明确不满足 | 生成按真实原因说明的S4；发送确认后进入筛选婉拒 |
| 等待问卷意愿 | 明确同意 | 待发问卷；有效链接和发送回执齐备后进入等待邮箱 |
| 等待问卷意愿 | 明确拒绝 | 礼貌收尾，进入婉拒笔试 |
| 等待问卷意愿 | 72小时未回 | 流失，不催办 |
| 等待问卷意愿 | 暂时没空但想之后做、模糊答复 | 转人工确认，避免误记拒绝 |
| 等待邮箱 | 无提交 | 保留等待状态，无超时任务 |
| 等待邮箱 | 候选人说已发送 | 记录自述，等待人工/邮件核验 |
| 等待邮箱 | 收件身份明确且两类材料齐全 | 待批改，创建人工待办 |
| 任意状态 | 明确要求停止联系 | 记录停止联系，暂停后续对外动作 |
| 人工接管 | 人工处理完成 | 由人工明确恢复到保存的阶段；不重新发整套话术 |
| 终态 | 新消息或新证据 | 转人工决定是否重开，不自动重置已发送记录 |

48小时、72小时分别从S6、S1的确认发送时间起算。生成草稿、发送失败或结果未知不启动计时。人工接管期间计时暂停；恢复时由人工确认剩余时长与下一动作。未来发送结果未知必须核对，不能自动重发。

## 4. 附件规则与待澄清处

原文要求收到“对方想发送附件简历”卡片时点击拒绝并发S7，但又把附件列为筛选信息源，二者需要拆开。当前草案建议：

- 新的待授权附件：目标策略为拒收并提示邮箱，不下载；真实动作当前关闭。
- 已可见的粘贴简历文字：可以作为信息来源。
- 已收到的附件文件：先交人工，不自动解析，等待你确认口径。
- 已婉拒：按原文仅处理卡片，不回复。其他终态也建议不发S7，避免恢复已结束沟通。
- 已人工接管或要求停止联系：停止包括拒收卡片在内的自动动作。
- 附件事件处理完回原流程，不视作通过初筛或同意问卷；同一卡片动作和S7应以附件请求ID去重。

原文S7可能在初筛通过之前就提示“完成问卷”，本版保留原文，并新增S7_BEFORE_TEST草稿：未发题时说明“如后续进入问卷环节”再提交，避免误导；不把附件引导当正式发题。
