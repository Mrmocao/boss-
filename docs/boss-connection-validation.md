## 当前代码入口

```powershell
node src/cli.mjs doctor
node src/cli.mjs login
node src/cli.mjs tabs
node src/cli.mjs status
node --test
```

- `doctor`：检查环境和端口，不检查账号、不启动浏览器。
- `login`：启动独立浏览器，用户登录；端口占用时停止，不启动第二个实例。
- `tabs`：只返回 BOSS 页面 ID 与无查询参数的路径。
- `status`：检测当前页面；即使出现招聘导航，也只报告特征检测，不确认业务验收。

`.runtime/chrome-profile` 保管浏览器会话，不得打包、提交或分享。专用窗口保持打开以便继续调试；关闭后需重新运行 login。会话是否有效由网站决定，不保证永久登录。
